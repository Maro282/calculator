# C# Console Calculator 🧮

A simple **C# console-based calculator** that performs basic arithmetic operations while handling invalid user input and preventing division/modulo by zero.

## 📌 Project Description

This project is a beginner-friendly console application built with C#. It allows the user to:

- Enter two numbers.
    
- Choose an arithmetic operation.
    
- Perform `+`, `-`, `*`, `/`, and `%` operations.
    
- Validate numeric input.
    
- Validate the selected operator.
    
- Prevent zero from being used as the second number.
    
- Perform multiple calculations in the same session.
    

The project was created to practice fundamental **C# programming concepts**, including loops, conditional statements, `switch`, input validation, and exception-prevention logic.

## 🚀 How to Run

### Prerequisites

Make sure you have the **.NET SDK** installed on your computer.

### Steps

1. Clone the repository:
    

```bash
git clone https://github.com/Maro282/calculator.git
```

2. Navigate to the project directory:
    

```bash
cd calculator
```

3. Run the application:
    

```bash
dotnet run
```

4. Follow the instructions displayed in the console.
